# 🏥 7 Heaven Hospital Management System

> **A complete web-based hospital management solution built with PHP, MySQL, HTML, CSS, and JavaScript.**

7 Heaven Hospital Management System is a web application developed to simplify and organize hospital operations through a centralized digital platform.

Patients can register, log in, view doctors, check doctor availability, book appointments, track appointment status, and view their billing records.

Administrators can manage doctors, patients, appointments, doctor availability, and billing through the admin panel.

## ✨ Key Features

👤 **Patient Management**
Patient registration, login, dashboard, profile, appointments, and billing.

👨‍⚕️ **Doctor Management**
Add, view, edit, and delete doctors with specialization and experience details.

📅 **Appointment Management**
Book appointments, check doctor availability, and manage appointment status.

🕐 **Doctor Availability**
Manage available days, consultation timings, and availability status.

💰 **Billing Management**
Create bills, manage payment status, and allow patients to view their billing records.

🔐 **Separate Authentication**
Dedicated login systems for patients and administrators.

📱 **Responsive Design**
Designed to work across desktop, tablet, and mobile screen sizes.

## 🛠️ Technology Stack

**Frontend:** HTML5, CSS3, JavaScript
**Backend:** PHP
**Database:** MySQL
**Server:** XAMPP
**Database Tool:** phpMyAdmin
**Editor:** Visual Studio Code

## 🎯 Project Goal

The goal of this project is to reduce manual hospital work, simplify appointment management, organize doctor and patient information, and provide a user-friendly digital healthcare management system.
